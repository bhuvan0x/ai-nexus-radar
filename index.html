AI-Nexus Radar

A self-healing scraper system that monitors Y Combinator's Job Board in real time — extracting emerging tech trends, salary data, and tech-stack signals. Built on Bright Data with an autonomous self-heal loop and a Sentiment Pulse engine.

View Live Pulse View on GitHub
Overview

The Self-Healing Scraper

Traditional scrapers break the moment a site changes its CSS. AI-Nexus Radar doesn't — it uses Bright Data's AI-Flow to rewrite its own extraction logic in plain English whenever the target page changes structure.

🧠

AI-Flow Self-Heal

Plain-language prompts drive the scraper logic. No CSS selectors to maintain — the AI re-derives them on every heal.

📡

Bright Data Collector

Browser-based scraping through Bright Data's infrastructure — handles JS rendering, IP rotation, and anti-bot protection.

📊

Pulse Score Engine

Transforms raw job postings into a 0–100 Sentiment Pulse using AI density, salary signal, and freshness signals.

🩺

Health Monitor

Continuously scans scrape output for gaps. When fields go empty, it generates the exact self-heal CLI command to fix them.

PHASE 03

Extended the collector in place to capture all 5 fields using a plain-language prompt. Scraper Studio's AI-Flow rewrote the extraction logic automatically. Preview returned all 5 fields — then approved for production.

PHASE 05

Health Monitor

src/health-monitor.js — scans scrape output for empty fields. When gaps are detected above a 30% threshold, it prints the exact self-heal CLI command to repair that specific field.

Engine

Pulse Score Algorithm

Three weighted signals combine into a single 0–100 score that tells you whether the AI hiring wave is surging or calm.

🤖

AI Density

Weight: 60%

Fraction of job postings whose tech_stack_tags contain any AI/ML keyword (GPT, LLM, PyTorch, LangChain, RAG, agents, etc.). This is the primary signal — it captures whether AI is actually being hired.

💰

Salary Signal

Weight: 20%

Fraction of postings that expose a salary_range field. High salary transparency correlates with mature, funded startups actively scaling.

🕐

Freshness

Weight: 20%

Fraction of postings from the last 30 days. Stale listings drag the Pulse down — a high freshness score means the market is actively hiring right now.

Formula: Pulse = (AI × 0.60 + Salary × 0.20 + Freshness × 0.20) × 100
≥ 70 → HIGH ≥ 40 → MEDIUM < 40 → LOW
