Built to survive the demo.

↯

Retry logic

Transient Bright Data/API failures use bounded exponential backoff with jitter.

Testable core

Health and scoring logic are reusable Node modules covered by automated tests.

Live-data contract: when the Vercel environment contains BRIGHTDATA_API_KEY, this dashboard uses the live server-side collector. If it is not configured, the UI clearly falls back to deterministic demo fixtures rather than pretending they are live.
