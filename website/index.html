Self-Healing Loop

The differentiator. When YC changes their HTML, the scraper rewrites itself using plain-language prompts — no manual CSS updates required.

Detect Gap
Health Monitor finds empty salary_range across 5/5 postings
↓

3
Preview Result

Approve & Verify
One command: bdata scraper approve c_msyndhlihcuensmoe
🔧 Self-Heal Command
npx -p @brightdata/cli bdata scraper heal \
  c_msyndhlihcuensmoe \
  "Extend the existing scraper to also extract:
   1) company_name — the name of the company
   2) salary_range — any salary or equity info
   3) tech_stack_tags — list of technologies
   4) posted_date — when the job was posted" \
  --pretty --json --timeout 600
